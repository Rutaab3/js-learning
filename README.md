> <h1><center>JavaScript Learning Notes

*JavaScript is a dynamically-typed, single-threaded scripting language that runs in the browser and on the server (via Node.js). It powers interactivity on the web — from simple button clicks to full-scale applications — and is one of the three core technologies of the web, alongside HTML and CSS.*

> **NOTE:** *This repository is a structured set of personal notes for learning JavaScript from the ground up — fundamentals first, building toward more advanced topics over time.*

---

## What's covered so far

**LESSON 1 — variables in JavaScript**
`var, let, const, scope, reassignment/reinitialization/redeclaration, hoisting, and the Temporal Dead Zone (TDZ).`

**LESSON 2 — JavaScript data types**
`Dynamic typing, the typeof operator, truthy and falsy values, type coercion, and common JavaScript quirks.`

**LESSON 3 — operators**
`Arithmetic, assignment, comparison, logical, unary, typeof, instanceof, ternary (conditional), and a beginner-level intro to bitwise operators.`

**LESSON 4 — logical patterns**
`if...else, else if, switch...case, and the return early pattern.`

**LESSON 5 — loops**
`for, while, and do...while.`

## Why these notes exist

`Learning JavaScript properly means understanding not just the syntax, but why it behaves the way it does — how scope works, why == and === differ, why hoisting can surprise you, and how the language quietly coerces types behind the scenes. These notes are written to build that understanding step by step, in a beginner-friendly order, without skipping the "why."`

---

## How the notes are organized

`Each lesson lives in its own folder, broken into individual .md files per topic — so each concept can be read, revisited, or referenced on its own without digging through one giant file.`
